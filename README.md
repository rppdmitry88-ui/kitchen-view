# Кухня · Живой объём

Интерактивная цветовая и пространственная концепция кухни: 13 палитр, две планировки, осмотр изнутри и выбор цвета правых шкафов.

Модель открывается в обычном браузере с поддержкой JavaScript и WebGL 2. Все компоненты включены в index.html, внешние библиотеки и изображения не загружаются.

Размеры и скрытые части условные. Это визуальная концепция, не рабочий проект мебели.
